# Shared Learning Resources: Faculty Contributions

The SOTE Command Portal is a discovery catalog, not the canonical storage location for contributed lessons. Faculty retain their source repositories and authorship.

## Propose a resource

1. Publish or identify a publicly shareable lesson in a faculty-controlled repository.
2. Confirm the lesson can be publicly linked, including embedded media and attribution rights.
3. Propose an addition to `data/shared-resources.json` through a GitHub pull request.
4. Provide `id` (unique slug), `title`, `author`, `type`, `topics`, `audience`, `format`, `source_url`, `preview_url` (when available), `repository_url`, `review_status`, `license_note`, and `added` (YYYY-MM-DD).
5. A reviewer verifies links, public-safe content, accessibility basics, and that the resource's status is accurate before merge.

## Boundaries

- Faculty lesson resources are not automatically validated operational knowledge articles.
- Student-authored CIT-205 troubleshooting articles remain in the classroom knowledge base.
- SOTE-framework governs portable instructional patterns, not CCAC course approvals.
- Do not include private student data, internal-only configurations, credentials, or restricted materials.
- Blackboard compatibility must be tested in Blackboard before labeling a lesson verified.
- When a lesson changes, update the catalog metadata rather than copying its HTML into the portal.
