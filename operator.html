Operator loop

Operate. Prove. Improve.

SOTE Operators do more than complete tasks. They leave behind evidence, documentation, and a clearer operating environment for whoever comes next.

1. Check the work

Start with the Project Dashboard and identify the mission, issue, or operational priority.

2. Work safely

Follow the documented scope, validate before changing systems, and preserve useful evidence.

3. Document it

Record what changed, what worked, what failed, and what another operator needs to know.

4. Hand it off

Update the project and improve the Knowledge Base so the work becomes part of SOTE.
