Students: Create and publish your portfolio

Start here, not in a blank GitHub repository. You will use an existing SOTE starter website to showcase real work from CIT-205. GitHub stores your portfolio and GitHub Pages makes it a public website. You do not need to design a website from scratch.

  1. Open the portfolio creation form. Select Create my portfolio repository on GitHub ↗. If prompted, sign into GitHub. Under Owner choose your own account, select Public, and name the new repository YOUR-GITHUB-USERNAME.github.io using your actual username. Select Create repository. The SOTE starter files will appear automatically.
  2. Personalize your page. In your new repository open index.html, select the pencil icon to edit, replace YOUR NAME and the sample text and URLs, then select Commit changes.
  3. Add a real assignment. Complete your existing CIT-205 artifact in Microsoft Word. Save the original, export a reviewed and sanitized PDF, then upload the PDF to your repository's artifacts/ folder using Add file → Upload files → Commit changes. Follow the artifact filenames guide ↗. In index.html, find its matching PDF link, remove the hidden attribute, and commit that edit. Leave unfinished links hidden.
  4. Publish your website. In your repository open Settings → Pages. Choose Deploy from a branch, then main and /(root), and save. After publication, visit https://YOUR-GITHUB-USERNAME.github.io/. Confirm your page and PDF open correctly on a phone.
  5. Submit the existing Blackboard assignment. Provide both the published website URL and the GitHub repository URL. Follow the existing ACE Portfolio Publication Mission ↗ for full instructions. If you already started, keep your current repository and work; do not start over.
  6. Optional: Get featured. After your site is employer-ready, request approval for the SOTE directory ↗. This is separate from your Blackboard submission, voluntary, and subject to instructor review.
